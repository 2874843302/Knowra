# 知序 Knowra

参考 Hyperknow 登录后页面的学习产品实现，采用浅色导航、白色工作区、深色文字与低饱和蓝色操作色。

## 启动

课堂朗读默认使用开源 **Kokoro v1.1（Apache-2.0）** 的自然女声（zf_006，流畅优先），默认语速 1.25×。在本机 CPU 合成，不调用浏览器原生朗读。**Chatterbox Multilingual Q4（MIT）** 亲切女声保留为高品质选项，可在白板设置中选择。安装脚本固定模型版本并校验权重 SHA-256，来源、许可证见下方“本地语音”。

技术栈：React 19 + Vite + Tailwind CSS + shadcn/ui + Radix UI + Motion + FastAPI + PostgreSQL。需要 Node.js 22+、Python 3.11+。

全站控件统一使用本地 shadcn/Radix 组件，业务布局按 Hyperknow 参考结构定制。Motion 使用 `motion/react`，统一处理按压、导航指示器、页面进入、进度与弹窗动画，遵循系统“减少动态效果”设置。部分动效由 EasyUI 源码适配，来源与授权见 `THIRD_PARTY_NOTICES.md`。主题、组件边界与维护规则见 `DESIGN_SYSTEM.md`。

Windows 首次安装：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.lock.txt
.\.venv\Scripts\python.exe scripts\setup-tts.py
.\.venv\Scripts\python.exe scripts\setup-expressive-tts.py
npm ci
# 配置 .env 的 KNOWRA_DATABASE_URL，启动 PostgreSQL（详见 docs/DATABASE.md）
docker compose up -d postgres
npm run dev
```

### 本地语音

- 高品质亲切女声（可选）：[Chatterbox Multilingual ONNX](https://huggingface.co/onnx-community/chatterbox-multilingual-ONNX)，MIT；安装到 `.local/tts/models/chatterbox-multilingual/`。中文参考录音来自 Apache-2.0 CosyVoice 的公开示例，固定版本和校验值见安装脚本与 `THIRD_PARTY_NOTICES.md`。安装后可在白板设置中选择，不覆盖流畅女声默认值。
- 模型：[Kokoro-82M-v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)，分发：[sherpa-onnx 官方量化模型](https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/kokoro.html)。模型许可证随安装包保留在 `LICENSE`，推理运行库使用 Apache-2.0。
- 课堂默认开启本地朗读，默认 1.25×，保留句间停顿。在“白板设置”可关闭、切换中文男女声/英语音色和调整倍速；这些选择随账号保存。旧版自动保存的 1× 会迁移到新默认速度，已有自定义速度和之后主动选择的 1× 会保留。未安装模型时仍可使用文字讲解，设置内显示安装提示。
- `/api/tts/status` 返回就绪状态和可用音色；`POST /api/tts/speech` 接受 `{text, voice}`（每段 1–600 字），返回 24 kHz 单声道 PCM WAV，均需登录。字幕与板书共用音频进度时钟，句间停顿保留，暂停和倍速不重新生成音频。
- 亲切女声使用 temperature/min-p/top-p 采样，并给无标点的片段补足句末停顿。较长内容按语义边界拆成最多 60 字的小段。缺少结束标记时会在时间预算内重试一次，仍失败则用本地备用女声完成本句；没有结束标记的音频不会播放或缓存。响应头 `X-Speech-Voice` / `X-Speech-Fallback` 标识实际音色与自动替换情况，备用音频按真实音色独立缓存，用户的默认音色选择不变。
- 进入课堂和暂停时也提前准备语音，每次最多预取五句，遇到课堂提问停止。每段讲解开始前先准备当前句及后续两句，播放时继续补充队列；暂停、倍速和重听复用缓存。音频按账号隔离存放在 `.local/tts/audio/`，总量限制为 512 MB，超出后淘汰旧音频。缓存读取不必等待其他合成任务；两种引擎独立排队。切换账号或离开课堂会停止播放并释放前端音频缓存。文本与音色不会发送到第三方服务。
- 可通过 `KNOWRA_TTS_MODEL_DIR` 指定 Kokoro 模型目录（Chatterbox 目录位于其同级）、`KNOWRA_TTS_THREADS` 设置推理线程数（Kokoro 默认 2，Chatterbox 至少 6、最多 8）。启动时优先预热流畅女声；高品质模型在选择后才于独立进程加载，避免首次加载占用 HTTP 进程的 GIL、阻塞登录和其他接口。本机 CPU 加载高品质模型约 50–60 秒，合成速度可能慢于播放速度，因此该音色仍可能等待。旧版默认女声会迁移到流畅默认值，之后主动选择的音色继续保留。重新启动后，磁盘音频缓存继续有效。

打开 http://127.0.0.1:5173 。开发模式同时启动 React 开发服务器（5173）与 Python API（8000）。端口需空闲。

若默认 PyPI 无法连接，可在安装命令末尾添加 `--index-url https://mirrors.aliyun.com/pypi/simple/`。

macOS / Linux 用 `python3 -m venv .venv` 和 `.venv/bin/python -m pip install -r backend/requirements.lock.txt`。后续 npm 命令相同。

生产模式：

```powershell
npm run build
npm start
```

生产模式由 Python 在 5173 同时提供 API 和 React 构建文件。其他端口可通过 PowerShell 的 `$env:PORT = '5174'` 指定。Node 负责启动进程，以及 MCP 后台课程生成使用的共享校验工作进程；API 请求由 FastAPI 处理。

## 已实现

### 语音提问

课堂右侧导师和即时协助的输入框均提供麦克风按钮。点击开始录音，点击方块结束并转写；文字会追加到已有草稿，可修改后发送。课堂录音前暂停讲解，发送后沿用当前课程的答疑和板书调整流程。录音、转写均可取消，关闭导师、切换对话或离开页面会释放麦克风；单次最长 60 秒。

识别使用本地 sherpa-onnx + SenseVoice Small int8，支持中英文，不依赖浏览器云端语音识别。原始录音仅在内存中处理，不保存到学习资料；发送后的文字作为正常提问保存。浏览器需通过本机地址或 HTTPS 打开并允许麦克风。

```powershell
.venv/Scripts/python.exe scripts/setup-asr.py
# GitHub 不可达时，国内镜像下载同一模型，并逐文件校验固定 SHA-256
.venv/Scripts/python.exe scripts/setup-asr.py --source modelscope
```

安装后重启后端。默认目录为 `.local/asr/models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17`，模型约 239 MB。可用 `KNOWRA_ASR_MODEL_DIR`、`KNOWRA_ASR_THREADS` 覆盖位置与 CPU 线程数。首次识别按需加载模型，后续复用。接口为登录保护的 `GET /api/asr/status` 和 `POST /api/asr/transcribe`（multipart `file`，单声道 PCM16 WAV）；输出 `text`、`duration`。

`npm run test:voice` 验证音频封装与草稿合并；`.venv/Scripts/python.exe -m pytest backend/tests/test_asr.py -q` 验证音频边界、重采样、鉴权和错误。`npm run qa:voice` 使用测试麦克风在 1440/1024 桌面验证录音、取消、转写回填、发送、课堂暂停和设备释放，识别结果及 AI 回答使用固定响应。真实本地模型可用 `.venv/Scripts/python.exe scripts/qa-asr.py <录音.wav>` 单独验证。

### 功能范围

- 首页：打造课程 / 即时协助、资料附件、自学 / 学校资料模式、继续学习、每周学习记录、推荐课程。
- 我的课程：列表 / 网格、搜索、进度筛选、移除和恢复加入。
- 课程集市：课程搜索、分类筛选、收藏、时长排序、课程预览、加入课程。

- 课程编辑：名称与简介、单元和讲次、学习目标、关键点、Markdown 讲义编辑，添加单元及讲次。
- 资料：Python 提取文档文字、搜索文件名和内容、文字预览、原文件下载、提取文字导出。
- 白板课堂：连续分栏白板 / 连续讲义、缩放、板书章节跳转、选中文字摘录 / 询问导师、摘录加入笔记、矩阵变换实验、笔记保存和导出、练习判分、语音朗读、对话历史 / 学习目标双视图。
- 学习数据：SQLite 持久化、注册时可选择导入旧版浏览器数据、保存失败提示与重试、缓存恢复、多标签页版本冲突合并。
- 学习动态：月 / 周日历、按日查看任务、创建 / 完成 / 删除任务。
- 历史：对话、课程活动、已完成课堂的搜索与删除。
- 设置：称呼、学习目标、模型连接、数据备份 / 恢复 / 重置。
- 账号：邮箱密码注册、登录、退出、HttpOnly 会话、账号学习数据隔离；登录后返回原课程链接。
- MCP：个人访问令牌、Streamable HTTP、后台生成任务、进度/取消/续生成、课程学习链接。接入方式见 [docs/MCP.md](docs/MCP.md)。
- 交互细节：6–8px 圆角、分层阴影、按钮按压、课程卡片悬停、滑动标签指示条和弹窗进场；适配手机触控与系统“减少动态效果”设置。

## 界面风格

在「设置与偏好 → 外观风格」选择水彩漫游、简约留白、书卷时光、林间呼吸或静夜专注。预览展示各套风格的字体、背景、颜色和卡片质感；点击立即应用到首页、课程、白板、即时协助和登录页，并自动保存到账号。刷新或更换设备登录后恢复账号选择，白板字体等独立偏好继续保留；可随时恢复原有水彩风格。

`npm run test:themes` 验证主题兼容、切换清理和基础文字对比度。`npm run qa:themes` 使用隔离账号及接口数据检查 1440/1024 桌面的五套主题、键盘选择、保存失败重试、刷新恢复和账号隔离，截图与结果位于 `.test/report/appearance-themes/`。

## AI 连接

在「设置与偏好 → AI 模型」保存多组模型，每组可设置显示名称、接口地址、模型 ID 和 API 密钥，并指定默认模型。首页、课程创建、AI 编辑和课堂提问处可切换默认模型；即时协助支持为每个对话单独选择模型，切换后保留消息与课程上下文。密钥仅保存在服务端，不返回浏览器；编辑时留空只保留当前这一组的密钥。删除模型不会删除对话，引用该模型的对话会回退到默认模型。

即时协助默认开启「联网搜索」，模型可按问题需要调用公开网络检索；普通概念问题可直接回答。搜索过程会显示查询词、执行状态、结果摘要与可点击来源，并随对话保存。输入区可关闭联网搜索，每个对话独立记忆。检索使用 Bing 搜索摘要，不抓取网页全文；失败或取消会如实显示。模型决策与工具执行通过 LangGraph 循环衔接，每轮最多两次检索，避免无休止搜索。

即时协助使用适配后的 EasyUI Chat，课堂与即时协助的老师回复共用 EasyUI AI Response：支持生成状态、Markdown/表格、代码与回答复制、参考来源展开、回答反馈保存，即时协助还可导出笔记和切换历史对话。翻看旧消息时停止自动跟随，可点击「回到最新」。样式跟随当前界面风格。组件支持传入流式状态，当前 AI 接口仍返回完整 JSON，未用定时器伪装网络流式输出。运行 `npm run qa:chat` 验证组件交互。

旧版单模型文件会自动兼容；运营方配置的环境变量作为初始默认模型。账号首次保存模型列表后，以自己的列表配置为准。

课堂白板支持拖拽平移、滚轮浏览、方向键移动和手机触摸；Ctrl + 滚轮以鼠标位置为中心缩放画布（70%–140%，向上放大、向下缩小），比例同步到白板设置，字幕与工具栏保持原位；右上角画布工具可切换文字选择或回到当前讲解。拖拽、滚轮、缩放和方向键操作不会暂停讲解；持续操作期间保留用户视角，松手或最后一次操作后 2 秒自动平滑聚焦到最新讲解，保留缩放比例。主动暂停不会被自动恢复。文字选择模式可摘录或向导师提问。

桌面课堂整页都是白板，AI 助手默认收起；顶部工具、字幕、大纲、笔记和练习均悬浮在画布上。打开或收起面板不改变板书宽度与分栏，工具栏也不会随画布平移或缩放。工具间的空白仍可拖动画布，当前讲解可自动跟随。笔记与练习打开时暂停讲解，白板保持挂载及原有位置；笔记继续自动保存。AI 面板独立滚动并保留未发送输入。`npm run qa:full-canvas` 验证 1024/1440/1920 桌面下的全屏尺寸、面板开关、拖拽、缩放、笔记保存和退出课堂后的页面滚动恢复。

板书按可用高度从上到下书写，一列达到界限后继续向右展开，保持同一块可拖动的连续画布。新增板书不会重新均分前面的内容；图表和短代码尽量保持完整，超长代码在块内滚动。回到当前讲解会定位到当前栏。`npm run qa:board-flow` 验证 1024/1440/1920 桌面下的长知识点换栏、已有内容位置、代码表格、助手开关及定位。

课程脚本支持在 `teaching.steps[].checkpoint` 中为对应知识点配置理解题，可以在一讲中穿插多题。学习者作答、查看解析后再继续；答题记录随播放进度保存，理解题不覆盖独立课后测验的成绩。新生成的多片段课程必须至少在一个非结尾片段安排理解检查，缺失或题目格式有误会在生成层自动修复。运行 `npm run qa:canvas` 可验证讲解中出题及画布交互。

在“设置与偏好 → AI 模型”填写兼容 Chat Completions 的基础地址（通常以 `/v1` 结尾）、模型 ID 和密钥。保存后可进行真实问答、课堂辅导和 AI 课程生成。也可通过 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 环境变量配置。

本机 DeepSeek 网页代理只需填写 `http://127.0.0.1:8787/v1`，模型名称和 API 密钥可以任意填写或留空，默认开启深度思考。此接入按地址识别，自动省略网页不支持的 `temperature`、`max_tokens`、`response_format`，课程 JSON 由系统提示词请求、生成层校验；请求超时为 360 秒，以容纳真实深度思考和生成。代理已经取消固定 30 秒本地等待及本地每小时、每天次数上限，通过检查后立即调用上游。连接配置保存成功只表示配置已保存，不代表已完成生成验证。所有调用共用一个上游会话，固定 12 小时切换，单并发、重复请求拦截和风险暂停仍生效。已知本地保护错误显示具体原因及有效的 Retry-After 秒数，保留 429/503 状态且不自动重试；不会展示原始上游错误文本。

逐讲生成使用课程草稿 ID 作为稳定会话标识，通过前端 `conversation_id`、后端 `session_id` 一直传到本地网页代理。同一课程的后续讲次、内容校验后的修复与截断续写共用原生父消息链；不同课程草稿隔离。暂停后继续或刷新后恢复仍使用原 ID；闲置满 10 分钟时由代理新建原生会话。变更前没有标识的历史网页会话保留，之后生成会从该课程的新稳定会话开始，不自动合并旧会话。

首个账号的密钥沿用本机服务的 `.local/provider.json`，后续账号使用 `.local/users/<user UUID>/provider.json`，不返回到前端，不写入浏览器备份。已有 Node 版本的模型配置继续使用相同文件。服务仅监听 `127.0.0.1`，拒绝外部站点的跨来源请求。

学习档案、账号、课程、进度、笔记、摘录、项目、日历、对话和生成任务保存在 PostgreSQL。通过 `KNOWRA_DATABASE_URL` 配置连接，建表迁移自动执行。上传原文件在 `.local/uploads/`。浏览器按账号保存本地缓存；清除缓存后重新登录同一账号，可从 PostgreSQL 恢复。旧 SQLite 数据迁移、部署、备份和测试说明见 [数据库文档](docs/DATABASE.md)。工作区身份由服务端账号确定，旧工作区 ID 不授予访问权限。

未配置模型时，课程模板、自主创建、内置讲义、练习、笔记和日历均可使用；自由问答和 AI 课程生成会明确提示连接模型。不会把固定回复伪装成 AI 输出。

课程按已确认蓝图逐讲生成，项目不再额外设置课程请求的 `max_tokens`；单次输出上限由所配置的模型服务决定。服务明确返回长度截断时，会携带已生成原文自动续写并拼接，不删减教材或替学习者压缩详细度。为防止异常模型无限续写，单次请求最多接收 8 段；空输出、重复输出、服务错误会停止，已完成的讲次保留。暂停或离开后不会再发起下一段续写。模型的上下文容量、服务默认输出上限和每段响应超时仍然适用。

当前讲次返回的 JSON 无法解析、单元或讲次与蓝图不一致、教材或板书/讲解脚本不完整、测验缺失或无效时，生成服务会携带具体校验原因自动重新生成当前讲次，最多尝试 3 次。期间保持正常生成状态，不显示中间错误，不重复保存已完成讲次。停止操作会取消等待和后续重试；持续失败时才保留进度并提示稍后继续。连接或授权等服务错误不按内容错误重复调用。

## 范围

这是可运行的学习工作区，提供服务端账号认证、按账号隔离的学习数据和 MCP 课程生成。尚未实现邮箱验证、邮件找回密码、第三方登录、支付订阅、社区发布或 LMS OAuth 同步。默认监听本机；远程 Agent 接入需自行部署并配置站点地址，详见 [账号与 MCP](docs/MCP.md)。

PDF 使用 Python pypdf 提取前 80 页文字，不包含扫描件 OCR；DOCX / PPTX 使用 ZIP 与安全 XML 解析提取正文 / 前 100 张幻灯片文字。单文件限制 15 MB，单次最多 5 个文件，单文件最多 15 万字符，工作区状态最多 25 MB。文字预览不还原排版，下载原件保留原始文件。

JSON 备份包含学习记录和提取文字，不打包原文件；更换安装目录时还需备份 `.local/` 整个目录及账号信息。阶段项目由学习者自评，不提供伪造的 AI 评分。板书摘录保存选中文字与页码，不改变原讲义。

AI 资料问答采用提取文字作为上下文，尚未实现完整向量检索；对话最多附加前 5 万字符的资料，课堂附加前 2 万字符。模型生成内容依赖所配置服务的可用性与准确性。

内置课程和题目为本项目编写的独立内容，非参考站的课程拷贝。每完成一讲以约 15 分钟估算学习目标进度，不是实际计时。

全局顶部栏在首页、课程、动态、历史、设置、即时协助和课程创建等主工作区页面统一固定；内容区通过共享高度变量预留空间，课堂保留自己的工具栏。内置线性代数课的交互演示嵌入对应的数乘、矩阵缩放、行列式和特征向量知识点，随板书进度变化；调整滑杆不中断讲解，点击重置可恢复讲解示例，不再向所有数学讲次追加独立实验室。

左侧全局导航可通过品牌旁的按钮完整收起，在顶部栏左侧重新展开；内容、固定顶部栏及课程创建输入区同步扩展。白板工具栏提供「手写板书」「清晰黑体」「书卷宋体」及字形预览，使用项目已有的本地字体，不改变代码的等宽字体。侧栏状态与板书字体保存到学习空间，刷新和切换讲次后保留。`npm run qa:appearance` 验证桌面的收起/展开、键盘焦点、布局对齐、字体切换、播放进度和偏好保留。

课堂提问现在会结合当前板书、已讲内容、答题结果和尚未讲的安排生成补讲。普通追问插入新的板书与独立讲解，明确要求改变学习方向时重排未讲内容；已经展示的内容与答题记录保留。理解题中追问会先补讲，再回到原题。右侧按「问题 → 解释与安排 → 讲解」排列，调整记录保存到学习空间，刷新后恢复。

模型通过 `classroom_adapt` 返回完整结构，校验通过后才应用到课堂，再用现有铅笔和逐字效果呈现；这不是提供方 token 的实时流式传输。结构校验失败在底层最多尝试三次，取消及最终失败均不应用半成品。`npm run test:classroom` 验证序列插入、重排、答题保留和请求恢复；`npm run qa:adaptive` 验证桌面真实页面中的联动、刷新和取消。浏览器使用固定模型响应，工作区使用真实本地保存，不代表真实模型的教学质量已验证。

课堂底部使用逐字呈现的当前语句字幕，不再显示步骤进度播放器；理解题在同一区域显示问题与选项，点击或键盘选择即提交，反馈后可继续讲解。右上角「白板设置」集中提供字体、白板/讲义视图、缩放、语速、朗读、摘录、下载和回放；画布只保留播放/暂停及拖动、选文、回到讲解。设置面板独立于画布缩放，字体与语速保存到学习空间。字幕独立于画布缩放、拖动，并为右侧浮层与底部导航预留空间。`npm run qa:lesson-stage` 和 `npm run qa:board-settings` 验证 1024/1440/1920 桌面下的字幕、答题、设置操作、键盘焦点和保存恢复。

### 课程独立练习

课程详情采用“面板”入口与“单元 / 资料 / 练习”三标签导航；左侧课程信息保持固定，右侧内容独立滚动。练习模块包含情境选择、应用思考与编程任务，共享到课堂的“独立练习”浮层。题库和作答分别保存在 `coursePractices`、`practiceAttempts`，不复用或修改讲义测验、教学中的 checkpoint 及其进度。开放题通过参考思路与逐项自评完成复盘，编程输入区不执行代码。

内置课程提供独立应用题。自建课程通过“补充练习”按所选单元调用 `course_practice`，只有用户点击时才请求模型；结构校验失败内部最多重试三次，取消和退出面板会丢弃迟到响应。`npm run test:practice` 检查题库、契约与取消；`npm run qa:practice` 验证桌面布局、作答保存、复盘和模拟模型的恢复流程。模拟响应不代表真实模型出题质量已验收。

`npm run test:questions` 验证选择、判断、填空、简答的统一契约与评分规则；`npm run qa:questions` 验证桌面课堂中的四类作答、对话历史、末题完成状态、刷新恢复及显式重播。填空按每一空的答案集合判断，支持声明的等价答案与大小写规则；简答对照参考思路复盘，不自动判对错。独立练习保留编程题，并为内置课程补充不同情境的题目。模型生成课程、课堂调整和练习的提示及校验也支持上述题型。

课堂末题确认后显示“本讲讲解已完成”，不再保留“继续讲解”按钮。继续问答与重播是分开的动作；只有明确点击“再听一遍”才清空本次作答并从头播放。连续点击中途问答的“继续讲解”也只前进一步。

课堂理解检查优先使用简短选择或判断题，只确认刚讲的概念。连接模型时，用户作答会自动触发一次针对该选项的补讲，分别处理理解正确与常见误区；新板书和口语解释接入当前讲解，随后回到原来的教学安排，不再追加考试。补讲不改写已展示内容，刷新不重复请求，同一问题重新作答会替换此前的针对性补讲；退出课堂或更改教学方向会取消迟到响应。未连接模型或请求失败时保留作答与已有解析，用户可以继续原课。独立练习仍支持多种题型。`npm run qa:checkpoint-feedback` 使用模拟模型响应验证答对、答错、内部修复、末题补讲、重答、持久化和取消，不代表真实模型教学质量已验收。

### AI 编辑已有课程

课程详情封面上的“编辑课程”默认打开 AI 编辑器。可以选择整门课程或指定讲次，用自然语言补充案例、修改深度或调整结构；AI 先返回方案，再逐讲更新需要修改的教材、独立板书、讲解脚本与测验，未涉及的讲次保留。新增、移除和重排都在完整预览中列出，只有点击“应用修改”才一次性保存；也保留原手动编辑入口。

原讲次 ID 保持不变，笔记和已学记录继续对应；仅更新内容的讲次重置旧讲解播放与补讲缓存，单元重排时同步调整阶段项目和已存独立练习的归属。生成取消、失败或退出均不会覆盖原课程，内容校验失败内部重试；课程发生变化后旧预览不可应用。`npm run test:course-editing` 检查方案约束、稳定标识、范围限制、取消及原子保存，`npm run qa:course-editing` 使用模拟 AI 响应验证桌面编辑、完整预览、应用与刷新、笔记/进度保留及失败取消。模拟交互不代表真实模型编辑质量已经验收。
